# 🚀 Sentiment Analysis Dashboard

[![Streamlit App](https://img.shields.io/badge/Live-Demo-blue?logo=streamlit)](https://aawhan0-sentiment-analysis-dashboard.streamlit.app)

Interactive dashboard analyzing **1.55M tweets**:
- **48% positive sentiment** (VADER)
- **8 LDA topics** (home/work/sad/love)
- Live tweet analyzer + filters/charts
- Streamlit + Plotly + scikit-learn

## 📊 Features
- Sentiment pie/heatmap (48/25/27%)
- Topic distribution bar chart
- Score histogram + live predictions
- Responsive design

## 🛠️ Tech Stack
Streamlit | Plotly | VADER | scikit-learn | pandas
